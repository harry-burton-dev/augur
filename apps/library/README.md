# Library app

The first app on AUGUR (working name). Users and departments keep document libraries and publish them for internal distribution, with a normalised reader view.

| Path | What it is |
| --- | --- |
| `manifest.json` | How the registry lists the app: route, entry, the intents it handles |
| `service/` | Libraries, documents, versions, publishing (`@apps/library`) |
| `frontend/` | The app's micro frontend (to come) |

Built after the platform's shell and core integrations.
