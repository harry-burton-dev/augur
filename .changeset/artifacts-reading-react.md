Artifacts' new layout no longer borrows Lit parts. Reading a document is React and Quill: the reader copy in the middle, its contents beside it, and its facts, lifecycle, links, Data Atlas and versions in the drawer. Sharing, publishing and publishing up are React dialogs, and "Change it" (tags, versions, the next version, rename, move, delete), a collection's or folder's Details (lifecycle, tags, links) and the Tags dialog now open in the new layout instead of the classic one. Only saved views and what came from below still open the classic layout. Marked words now reach Data Atlas from the new layout with the document they came from.
