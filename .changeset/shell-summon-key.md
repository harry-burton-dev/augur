The one-key shortcut that opens the shell (`) can be turned off, and the choice follows the person to any browser (WCAG 2.2, 2.1.4 Character Key Shortcuts). Account, About, Keys has an "Open with `" switch beside the keys list, and so does the Shell's own Settings; Ctrl or ⌘ K always opens it. Identity keeps `summonKey` in a person's preferences. The shell takes shell-kit 0.15.0, where a text field keeps a ` typed in it.
