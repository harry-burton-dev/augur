Admin is on React and Quill (PER-243), in the three-column frame with its sections in the rail and the Upgrade Centre one press away. Its Upgrade Centre page has gone, as ADR 0030 said it would after one release: what was the Updates screen is now **Dev to production**, showing the line from dev to production and sending you to the Upgrade Centre to upgrade, hold or go back. Status's "a release is out" note opens the Upgrade Centre too. **Go back** on an installed app now opens its confirmation; before, it did nothing for any version other than the newest.
