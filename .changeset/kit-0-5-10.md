On kit 0.5.10, the shell draws the frame round an app on the app contract: the command palette over the commands it declares (Ctrl+Shift+P or ⌘⇧P, or Alt+Shift+P), each one it hasn't loaded yet locked with why; the radial menu on the things it marks, sending the command with the thing; and the About panel with the sections it declares, each saying so until the app fills it.
