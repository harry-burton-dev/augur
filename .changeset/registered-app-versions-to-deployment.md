An app its own service registers gets a page in Deployment, as installed ones have: which kept version the shell is given, holding it there or following new versions, and a new sign-in for its service. Admin's Apps no longer has versions or a new sign-in; it sends you to the app's page in Deployment. The gateway lets AUGUR's own Admin read the organisation's settings and the floors a person is on, so Admin can run on the app contract.
