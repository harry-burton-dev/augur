Two places say what a release brings:

- **[Upgrade notes](upgrade-notes/)**: what an admin must do or know when upgrading, newest first. Each note says
  which release it came in. Read the ones between your release and the one you're moving to before you
  [upgrade](../run/upgrade/).
- **The release itself**, on [GitHub's releases page](https://github.com/harry-burton-dev/augur/releases): every
  change to each part, the breaking ones, and the new settings.
