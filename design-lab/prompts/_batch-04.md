# Batch 4: platform features

Written 3 November 2026 at Harry's request ("prompts for platform features
other than UI and work outputs"): how the services under the screens
should behave, and how people see and steer that behaviour.

| Prompt | Kind | Feature | Field | Steers on |
|---|---|---|---|---|
| [N Keys and doors](n-keys-and-doors.md) | steered | identity and access | master key systems, delegation, access reviews, break glass | mine-versus-ours, consequence-preview, data-wears-its-label |
| [O The switchboard](o-the-switchboard.md) | steered | notifications, events, inbox | switchboards, the post, on-call and escalation | shell-owns-loudness, answer-not-announce, earned-sound |
| [P The index](p-the-index.md) | steered | search across apps | back-of-book indexing, union catalogues, command palettes | the-workings-show, the-record-has-edges |
| [Q The apprentice](q-the-apprentice.md) | steered | agents and the model gateway | apprenticeship, clinical delegation, levels of automation | consequence-preview, the-workings-show, visible-repair |
| [R The constitution](r-the-constitution.md) | steered | settings, policy, feature flags | constitutions, point-in-time legislation, the cascade | the-object-explains-itself, changes-before-they-bite |
