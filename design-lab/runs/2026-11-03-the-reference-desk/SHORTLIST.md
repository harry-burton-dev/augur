# Shortlist: the reference desk

Ranked by what I'd build first. The headline: **an operator can ask Data Atlas a vague question and trust the answer if the model only ever writes in pencil.** Five of six surfaces reached the same rule on their own. A model may propose, ask and match, but it never enters a count. So turning the model gateway off changes the route to an answer, never its numbers.

**Worth keeping as options:**
- [Identification key](ask/v4-key.html): the most-splitting question first, with no model. This is what working without the gateway looks like.
- [The answer is a range](cant/v5-the-range.html): "10 to 22" when coverage is partial.
- [Where I looked](cant/v3-where-we-looked.html): places by months. "Not found" is not "none".
- [Two transcripts](grammar/v6-two-transcripts.html), as a teaching page for admins.

**Not worth pursuing:** the [bridge](ask/v3-bridge.html) drawing (keep only its question, "what is the answer for?"), [Leiden marks](grammar/v2-leiden-marks.html), [rings of difference](example/v5-rings-of-difference.html), and the [two desks](saved/v4-two-desks.html), which only fit an admin review.

**Answers to the prompt's questions:**
- *What does the model gateway do, and what must work without it?* The model reads free words as kinds and details, proposes readings of loose words, and matches by meaning ("alike by meaning", supplier names spelt differently). Everything else works without it: drafting from Data Atlas's own matching (keys, names, spelling), the method card, base and balance, ask by example, saved questions and reruns. Without the model the person does more work (a tick list or a key). The answer must also say "3 records matched nobody", or it reads surer than it is (V2's H key shows the dishonest version).
- *How does a person tell a guess from a fact?* By material. A guess is pencil: dotted, italic, in its own lane, and never counted. A fact is ink. An accepted guess keeps a mark of who proposed it, because provenance never washes out. Sentences come from templates, so the plain words always match the real steps.
- *What must a question record to be rerun honestly?* Its words, each sharpening choice and who made it (person or model suggestion), its steps, when it was asked, and whose access each run used. It never records the rows. A rerun uses the data as it is now by default, offers "as it was" for comparison, and never calls the model. A change notice names one of five reasons: something happened, we learned about the past, different access, a guess was settled, or a word changed meaning.

**Where these push back:**
- Sharing a question with its count leaks. If Sam's 7 travels with the question, Priya's 5 tells her exactly how many suppliers are hidden from her. That breaks the catalogue run's "some, never a number". Recommendation: share the question without the sharer's count.
- Without the model, an answer can look surer than it is. Unmatched records must always be counted on their own line.

**Decisions for Harry** (none taken):
1. Does a shared question carry the sharer's count? I recommend no, for the reason above.
2. Without the model, may the person place unmatched records with a key, or do they only wait in Triage for the keeper?
3. Must a partly covered count always be given as a range ("10 to 22")?
4. Is there a cap on how many errands one question may send to each keeper?
5. The pencil mark (`--x-proposed-guess`: italic, dotted edge, its own hue) belongs beside the six empty marks in the kit. Artifacts and Mandate need it too, so it needs a small record.

**Gaps:** the guess mark and lane tokens; a template sentence per step (Data Atlas has none yet); per-record "matched nobody" counts from Data Atlas matching; a saved-question object (words, choices, steps, access per run) and where it lives (Data Atlas or Artifacts); events that say which of the five reasons moved an answer.
