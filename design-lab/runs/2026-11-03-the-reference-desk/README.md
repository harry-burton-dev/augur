The fifth design lab run (3 November 2026), the second of batch 3, "data for operators": what **asking data a question** looks like for an operator who has never written a query, when it works like a good reference desk, with or without a language model behind it. Sources: Dervin and Dewdney's reference interview, Zloof's Query by Example, Shneiderman's dynamic queries, pivot tables, identification keys, and research on showing generated queries back to people.

36 prototypes over six surfaces (question sheet, the ask, ask by example, the answer with its workings, when the data can't answer, saved and shared questions) and four combined screens. All sample data is a regional services organisation. Each page plays its moment about 1.2 s after load. **R** replays, **G** turns the model gateway off (no number changes), and **T** shows the technical names. Start with [One question, a week later](combined/v1-one-question-a-week-later.html) and [With and without the model](combined/v2-with-and-without-the-model.html). The prompt is in `prompt.md`, the ranking in `SHORTLIST.md`, new concepts in `concepts.md`.
