The third design lab run (3 November 2026): whether AUGUR could use **sound** the way a cockpit, a film's sound design or a well-made instrument does: almost silent when things are normal, unmistakable when something needs you, and carrying real information (which floor, how urgent, how many people) instead of decoration. Sources: Brewster's earcon guidelines, avionics aural alerts, Murch's room tone, Weiser's calm technology, Apple Audio Graphs, Braun detents.

Every sound is generated in the browser with the Web Audio API from parameters, so it can be tokenised like colour. Nothing plays until you click **Enable sound**. Each page has mute, per-category volume, reduced sound and a caption strip that writes out every sound, so it reads without audio and in screenshots. **R** replays each moment. Nobody has listened to these yet: the numbers follow the guidelines, but whether they work needs Harry's ears, starting with [A full day in two minutes](combined/v1-full-day-in-two-minutes.html). The prompt is in `prompt.md`; new concepts are in `concepts.md`.
