# Concepts found by this run

Each is bigger than one prototype and could steer a future run. New ones are also filed in `design-lab/concepts/`.

## Raw and kept (`raw-and-kept`)
A value as it arrived (typewriter on a ruled ground, never changed) and as AUGUR keeps it (plain type, a dotted seam and the number of the line that made it) are two visible materials, so anyone can see which values were touched and ask what each was. Evidence: grammar V3, by-example V5, combined V2 and V4. Could steer: the form (X), the label (L), any import.

## Stop, don't guess (`stop-dont-guess`)
A step that can't read a value stops at the first misfit of its kind, asks with the row's own context and the other answers, and runs nothing after it; it stops only when a guess would change what lands, and groups misfits with one cause. Evidence: by-example V6, next month V1 and V3, combined V1 and V2. Could steer: the groundskeeper (K), the form (X), Upgrade Centre migrations.

## Every answer is a line (`every-answer-is-a-line`)
An answer is written where it will be reused, and the acknowledgement ("heard") names that place; answers change the recipe as a new version with its reason, never the data already made, so a rerun asks only about what is new. Evidence: grammar V4, next month V5, combined V1 and V2. Could steer: the constitution (R), the switchboard's rules, Triage at volume.

## Rehearsed to the pass (`rehearsed-to-the-pass`)
Automation prepares everything up to the check before anything leaves and waits there; normal runs are silent, only a stop reaches "Needs you", and a person always does the pass. Evidence: next month V6, V3 and V4, combined V1. Could steer: the groundskeeper (K), the edition (S), rollouts.

**Also advanced:**
- **The recipe is the record** (now explored): the recipe, version, line and run model in the shortlist; per-value provenance.
- **Visible repair** (now explored): undo keeps the line struck through; recipe versions with reasons; a late tray answer as a seam.
- **Consequence preview**: the pass (make, change, link, set aside, not brought in) and what landing moves elsewhere.
- **The answer has a base**: the pass balances against the source's own TOTAL; every line and every value is accounted for.
- **Ask only what changes**: settle what the file's evidence settles, and show that evidence.
- **Pencil and ink**: the model proposes links between lines from their notes, never codes; G changes no count.
- **Trust changes the sample**: taste where a person's answer touched, plus a seeded random few, and the decider tastes the same plates.
- **The structure predicts its gaps**: a column with no place becomes a word asked for, with its waiting records.
- **Waiting is a place**: held proposals and words asked for.
- **Dark when normal**: the andon board and the quiet rerun.
- **The record has edges**: "not known yet" (a value set aside) versus "not brought in, said".
