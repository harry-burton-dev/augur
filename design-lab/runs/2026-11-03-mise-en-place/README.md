A design lab run (3 November 2026), from batch 3, "data for operators": how an operator who has never heard of ETL can **turn raw data into something usable** themselves: bring a messy spreadsheet in, see what it holds, tidy it by example, map it to the kinds of thing Data Atlas keeps, check it at the pass, send it to Triage, and rerun the saved recipe on next month's file. Sources: the kitchen brigade (mise en place, the recipe, the pass, "heard"), Wrangler and predictive interaction, Power Query's applied steps and OpenRefine's clustering, recipe cards, knitting patterns and IKEA's wordless instructions, and Toyota's jidoka.

The run has 36 prototypes over six surfaces (the kitchen sheet, bringing a file in, tidying by example, mapping to what we keep, the pass, next month's file) and four combined screens. All sample data is one realistic messy file: Kestrel Fleet Services' October visits for a regional services organisation (merged title, empty lines, an exact copy, van numbers five ways, dates in four shapes, ten spellings of three depots, results with notes inside, an odometer that says "c.12k", a loan van with no number, a TOTAL line), then November's file with two new problems (a renamed column and a result nobody knows). Every count on every page is worked out by running the recipe over those lines (`_src/lib.js`), so the pages agree. Each page plays its moment about 1.2 s after load. **R** replays and **T** shows the admin words (what each recipe line compiles to); some pages add **G** (model gateway off). Start with [From drop to Triage, and a month later](combined/v1-drop-to-triage-and-a-month-later.html) and [The bench](combined/v2-the-bench.html). The prompt is in `prompt.md`, the ranking in `SHORTLIST.md` and the new concepts in `concepts.md`.

Pages are built by `_src/build.py` from `_src/common.css`, `_src/data.js`, `_src/lib.js` and each surface's `_src/v*.src.html`; the built pages link the shared kit. Every page was checked by screenshot at 1600×900 and 1280×800, and with reduced motion, after pressing T, G and R: no console errors or warnings, no page scroll, a caption on every page.
