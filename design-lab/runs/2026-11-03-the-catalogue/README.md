The fourth design lab run (3 November 2026), the first of batch 3, "data for operators": whether an operator who has never written a query or seen a schema can read **the structure of what AUGUR keeps** in Data Atlas: kinds of thing, details, links, and what is missing. Sources: Ranganathan's faceted classification (PMEST), library catalogue cards and authority files, field-guide keys, the periodic table, Wikidata item pages, Isotype's transformer.

36 prototypes over six surfaces (grammar, the shape of what we keep, a record card, placing a new thing, facets for finding, when the structure changes) and four combined screens. All sample data is a regional services organisation, so nothing is tied to one deployment. Each page plays its moment about 1.2 s after load, **R** replays and **T** shows the technical names. Start with [An operator's first day](combined/v2-operators-first-day.html) and [Three ways to read](combined/v1-three-ways-to-read.html). The prompt is in `prompt.md`, the ranking in `SHORTLIST.md`, new concepts in `concepts.md`.
