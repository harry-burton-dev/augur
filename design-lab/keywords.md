# Keyword bank

Search terms for finding the next prompts. Each row is a field outside
software with the terms that turn up real techniques in it, a few seed
sources, and the AUGUR surfaces it could feed. When a run or a batch uses a
row, mark it in **Used by**. Add rows whenever research turns up a field
worth a run; a wildcard should come from a row nobody has used.

How to use it: pick a row, search its terms plus "design", "notation",
"standard", "manual" or "case study", read two or three primary sources,
then write the prompt with "what to take from each".
