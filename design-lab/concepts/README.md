# Concepts

High-level ideas found by design lab runs, bigger than any one prototype.
They steer which prompts get written next. Each run adds or updates
concepts here from its own `concepts.md`.

Status: **to explore** (proposed, no run yet), **exploring** (a run is on
it), **explored** (a run has a shortlist), **adopted** (a decision record or
app pattern took it), **dropped** (say why in the file).
