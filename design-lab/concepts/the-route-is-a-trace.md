# The route is a trace

Routing is one function that, for every notice and every person it names, returns a trace: the rule that decided, the channel, the time, what held it, and every escalation step, each with whose setting it was. Every "why" a person, a team lead or an app owner sees is a rendering of that same trace (a postmark in the list, hops in the item, a replay of the week, a delivery report), so the explanation can never drift from what happened.
