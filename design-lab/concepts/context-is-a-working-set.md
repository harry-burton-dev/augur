# Context is a working set

Data becomes information when it is given meaning, and context when it is placed against a reader, a task and what else is going on. Context should be an object people can see, review, hand over and keep: the working set for one task, assembled from what AUGUR holds, each piece saying its rung (data, information, context), why it is there, for whom, and since when. The same working set is what an agent is given, so a person can review it. From DIKW and its critics, Bateson, Endsley's situation awareness, the data/frame theory of sensemaking and Tilden's interpretation.
