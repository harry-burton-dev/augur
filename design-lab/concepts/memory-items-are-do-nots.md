# Memory items are do-nots

When automation has already acted (the updater went back by itself), the first lines a woken person reads must stop them repeating or undoing it: touch nothing, note the way back by name, start a log. A pilot's memory items are actions because the aircraft waits for no one; AUGUR's are holds, because AUGUR has already done the urgent part. A card that opens with an action invites the restart, the retry and the go-back.
