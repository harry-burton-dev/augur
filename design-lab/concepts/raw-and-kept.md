# Raw and kept

A value as it arrived and a value as AUGUR keeps it are two visible materials. Raw is typewriter on a faint ruled ground and is never changed or lost; kept is plain type with a dotted seam and the number of the line that made it. Anyone can tell, at text size and without a legend, which values a person or a recipe has touched, and ask what each one was.
