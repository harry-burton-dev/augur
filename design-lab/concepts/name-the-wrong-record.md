# Name the wrong record

When a conclusion is withdrawn, the record that misled it is marked discredited, with who and why, and stays where it is. Records say; conclusions believe; a conclusion cites records for and against. So "why did we think that?" points at a record, and the same record can't mislead the next keeper the same way. From the Genealogical Proof Standard's split between evidence and conclusion.
