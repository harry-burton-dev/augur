# Every answer is a line

When a person answers a question the system asked, the answer is written where it will be reused (a numbered recipe line, a rule, a setting) and the acknowledgement names that place ("heard: recipe line 6 now also sets aside a line with no van number"). So the same question is never asked twice, a rerun stops only for something new, and an answer changes the recipe, as a new version with its reason, never the data it already made. From the kitchen's call and "heard", and knitting-pattern errata.
