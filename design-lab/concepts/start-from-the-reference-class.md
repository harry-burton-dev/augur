# Start from how it usually goes

Any forecast, term or deadline starts from how things like it went here before: a class of the organisation's own past cases, shown as a count ("4 of 11 recovered within 6 months"), never a percentage. Each move away from the count is a separate, stated step with who made it and why. The choice of class is shown, and other classes are one click away, because the class changes the count. The forecast is kept to be scored, and becomes one more case. From Kahneman and Lovallo's outside view and reference class forecasting.

First found in: [`2026-11-03-the-analysts-bench`](../runs/2026-11-03-the-analysts-bench/) (combined V1 stage 1, premortem V5, choose V4, kept V3).

Could steer: Mandate deadlines, Upgrade Centre (how long upgrades like this took), Data Atlas (a contract outcomes register), the case file (U).
