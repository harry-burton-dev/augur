# Found the same, or became one

Two kinds of merge that look alike and must never be stored alike. *Found the same* (two records were always one company) changes only what we know, so it moves recorded time and no valid time; undoing it replays the past exactly. *Became one* (one company bought and folded in another on a date) is an event in the world, with a valid date. The run recommends keeping merges for the first only, and recording the second as a link between two entities that both stay.

First found in: [`2026-11-05-the-type-specimen`](../runs/2026-11-05-the-type-specimen/) (grammar, merge V2, across time T3, combined probes).
