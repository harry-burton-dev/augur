# Every note knows its release

A note written before its release exists says so (`From unreleased`), and the release fills the number in. Without it the reader's first question, "does this apply to me?", can't be answered by any text or filter. In AUGUR's upgrade guide 34 of 37 notes had no release, because a note is written in the pull request, before the version is decided.

First found in: [`2026-11-05-the-safety-card`](../runs/2026-11-05-the-safety-card/) (all whole-set variants, next-note V4). Reader test: every reader, on every text, said they couldn't tell which notes apply to their server.

Could steer: the Upgrade Centre's filter by version, app changelogs, Mandate intents that wait for a release.
