# Trust by the kind

Autonomy is set per kind of work, not per agent. Four rungs (Shadow, Asks each time, Asks for the batch, Acts then shows), none above 3: a person is always the master. Each kind has a cap set by AUGUR and the app (facts for Data Atlas cap at 2, because nothing skips Triage), and the supervisor sets the rung within it with a reason. Widening needs evidence from work people already checked (a replay in the shadow); a mistake narrows only the kind that failed.
