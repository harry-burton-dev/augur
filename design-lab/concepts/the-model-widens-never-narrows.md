# The model widens, never narrows

In any judgement, a model may add possibilities (an explanation nobody listed, a reason it failed, the case against, a fact worth finding) and may never remove or rank them (mark, rank, drop, choose, set a word). What it adds arrives empty and untested, and only a person fills it in. It is a test anyone can apply to a model output: did it add a possibility, or take one away? Turning the model off must leave every mark, count and result unchanged. From the Tradecraft Primer's devil's advocacy and the reference desk's pencil and ink.
